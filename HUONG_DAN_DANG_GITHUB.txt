CẬP NHẬT WEB 2.1
1. Giải nén gói web này trên máy tính.
2. Mở https://github.com/lamhuunhan1999/xuat-cao-do-ho-ga
3. Add file → Upload files. Kéo các tệp và thư mục đã giải nén vào thư mục gốc repository, rồi Commit changes.
   Không tải nguyên tệp ZIP lên làm trang web. Không đưa DWG hoặc CSV khảo sát vào repository công khai.
4. Tệp cần cập nhật: index.html, app.mjs, engine.mjs, worker.mjs, style.css; nên cập nhật cả README.md và hướng dẫn này.
   Giữ vendor, zip.mjs và các tệp giấy phép. Gói này có đầy đủ các tệp đó.
5. Chờ GitHub Pages triển khai xong, mở https://lamhuunhan1999.github.io/xuat-cao-do-ho-ga/ và nhấn Ctrl+F5.
   Kiểm tra dòng PHIÊN BẢN 2.1 WEB.
6. Chọn Drawing1.dwg và đọc. Nếu có 4 cặp cọc gần trùng nhưng khác hướng, chọn tên cọc trong từng ô theo hồ sơ rồi bấm Đọc DWG và tạo CSV lần nữa.
7. Tải bộ CSV. Trong HGCAODO chọn nguồn cao độ CSV và nguồn cọc CSV tương ứng.

Gói này là bản cập nhật để tải lên; việc tải gói về không tự thay đổi website đang chạy.
