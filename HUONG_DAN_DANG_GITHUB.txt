ĐĂNG CÔNG CỤ DWG → CSV LÊN GITHUB PAGES

Bản web đã được tạo và kiểm thử. Kết nối GitHub trả lỗi 403 (Resource not accessible by integration) khi ghi nên chưa cập nhật được repository.

1. Giải nén HG_DWG_CSV_v2_GitHubPages.zip.
2. Mở repository https://github.com/lamhuunhan1999/xuat-cao-do-ho-ga trong trình duyệt bạn đã đăng nhập.
3. Chọn Add file → Upload files.
4. Kéo tất cả FILE VÀ THƯ MỤC bên trong phần vừa giải nén vào GitHub. Giữ thư mục vendor nguyên vẹn.
   index.html phải nằm ngay thư mục gốc repository, không nằm trong một thư mục bao ngoài.
   Không tải nguyên ZIP lên để làm website.
5. Chọn Commit changes (nhánh main). README.md sẽ được cập nhật; trang gốc nằm trong archive.
   File index.html. cũ có dấu chấm cuối có thể để lại, vì index.html mới là trang chủ đúng tên.
6. Settings → Pages → Source: Deploy from a branch → main → /(root) → Save.
   Nếu đã có cấu hình này thì giữ nguyên, chờ lượt xuất bản hoàn tất.
7. Mở https://lamhuunhan1999.github.io/xuat-cao-do-ho-ga/ và tải lại trang.

DÙNG CÔNG CỤ
Chọn DWG → Đọc DWG và tạo CSV → kiểm tra kết quả → Tải bộ CSV.
Trong ZWCAD: HGCAODO → CSV cao độ: CaoDo.csv → CSV cọc: Coc.csv.
Không cần chạy CMD, không cần cài Python. Lần đầu cần Internet để tải bộ đọc khoảng 7,5 MB.
Bản vẽ không được gửi lên máy chủ. Công cụ không đọc NTD và chưa đọc cọc/điểm trong block hoặc Xref.

Nếu tải trang mà vẫn thấy giao diện cũ, kiểm tra Actions/Pages đã xuất bản commit mới thành công rồi tải lại.
Nếu báo thiếu worker.mjs, engine.mjs hoặc vendor/libredwg-web.js, kiểm tra đã tải đầy đủ file và thư mục ở bước 4.
